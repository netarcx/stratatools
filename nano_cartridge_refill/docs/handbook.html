Cartridge Refill Unit

This cartridge has a refill unit built into it. One button, two lights, and nothing to install. This covers everything it can tell you and what to do about it.

Five things, and only two of them you touch: the switch and the button. The switch sits between the red light and the button; the button sits between the switch and the USB-C socket.

Before you start

1 · Switch on

The switch — between the red light and the button — connects the unit to the cartridge's chip. It must be on. With it off the unit cannot see the cartridge at all, and everything you try reports code 1-1.

2 · Plug in

Power is USB-C. The unit starts as soon as it has power, and you will see the light test straight away.

Switch it off again before the cartridge goes in the printer

Left on, the unit holds the chip's data line down and the printer cannot read the cartridge at all — it will report a missing or unreadable cartridge. Off is the normal position for printing; on is only for refilling.

The button

Tap

Check the cartridge and report what it holds. Reads only — it cannot change anything, so use it freely.

Hold 1 second

Refill it. The green light comes on solid while it works, then blinks three times when it is done.

Hold while plugging in

Restore. Hold the button down, then plug in the USB-C, and keep holding. This puts back the last known-good contents, and is how you recover from a failed refill.

Every time it powers on

Green ×2 · Red ×2 · Both

Every time you plug in the USB-C, the unit tests its own lights first, so you always know the lights themselves still work. It takes about two and a half seconds.

If a light never comes on, it is dead — and every message it would have carried is lost. If red runs before green, the two lights are wired the wrong way round and every code you read afterwards will be back to front.

Reading the lights

Green, steady. Working. Leave it alone until it stops.

Green, slow blinks. Finished, and all is well. Count them: 2 checked · 3 refilled · 4 restored.

Red blinks. Something went wrong. It gives a few long blinks, a pause, then a few short ones — count each. Long-then-short is the code, so two long and three short is 2-3. It repeats three times, then red stays lit.

Red stays on. The last thing it did failed. It stays lit until the next time you use it, so this still tells you the truth hours later.

If something goes wrong

Red flashing fast and non-stop from the moment it powers on

The unit failed its own internal self-test and will not operate at all. This is not a cartridge fault. Do not use it.

Recovery is always the same

Switch on, hold the button down, plug in the USB-C, and keep holding. That restores the last known-good contents. The unit saves a copy before every write, so there is always something to go back to.

A refused operation is a working unit

Codes 2-1, 2-3, 3-1, 3-4, 4-1 and 4-2 all mean it stopped before changing anything. Refusing to write is the unit doing its job, not failing at it.

How a refill works

When you hold the button, the unit reads the cartridge, checks the contents really are a valid P-class cartridge, and saves a copy of them to its own internal memory. If that copy will not save, it stops there and writes nothing.

It then sets the remaining material back to full, gives the cartridge a fresh serial number, and writes it back. Afterwards it reads the chip twice — half a second apart — and checks the result is genuinely valid before it shows you three green blinks.

That second read matters: it catches data that looked right immediately after writing but did not hold. Three green blinks means the cartridge was read back and confirmed, not merely that a write was attempted.
